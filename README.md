# CodeAlpha Calculator

This is a small calculator project made with HTML, CSS and JavaScript.

## What it can do
- Add, subtract, multiply and divide
- Work with decimal numbers
- Convert a number to a percentage
- Change a number between positive and negative
- Clear the display or delete the last character
- Use the keyboard as well as the on-screen buttons
- Show an error if you try to divide by zero

## Run it
1. Download or clone this folder.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.

## Keyboard controls
- Number keys: enter numbers
- `+`, `-`, `*`, `/`: choose an operation
- `Enter` or `=`: calculate
- `Backspace`: delete
- `Escape` or `C`: clear
- `%`: convert the current number to a percentage

## Quick checks
- `12 + 8 =` should give `20`
- `9 × 6 =` should give `54`
- `50 %` should give `0.5`
- `8 ÷ 0 =` should show an error
